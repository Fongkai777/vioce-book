## 复现自动化检查

```bash
pnpm install --frozen-lockfile
pnpm check       # 发布边界、lint、类型、离线测试、生产构建
pnpm audit       # 完整依赖审计，CI 也会执行
```

无需生产或模型密钥。CI 固定 action 修订、按锁文件安装，执行生产及完整依赖审计和上述检查，不持有部署凭据。排队中的 CI 不能写成通过。

测试还覆盖 PDF 提取、元数据/内容分离与迁移、引用、长历史摘要、语音草稿/播放、注册竞争、token 结算和依赖兼容。SQLite 能检查 SQL/事务，但不能复现 Cloudflare 调度、D1 故障或 Worker 资源上限；离线测试不衡量回答质量和真实声学。

本地 fixture 为 `tests/fixtures/book-qa.tsx` 和 `voice-qa.tsx`。仅临时从本地路由导出，提交前移除；发布检查拒绝 QA 路由。一次性数据库注册/恢复演练、安全条件和已记录观察见[附录](EVALUATION-LOG.zh-CN.md)。破坏性脚本禁止指向生产。

## 每次发布的人工检查

记录提交、浏览器/系统、fixture、实际结果与证据。没执行的项保持未验证。

- 迁移、管理员初始化/登录、普通用户权限拒绝、账号管理与旧数据保留。
- 新文字 PDF、扫描页 OCR、重开不重新 embedding、引用到 PDF、未知页码处理。
- 拒绝麦克风权限、自动发送/播放、打断、空识别、静音/停止、重试、刷新及断网/额度错误。
- A/B 书库、历史、偏好隔离，主动反馈同意与示例副本独立。
- 键盘焦点、宽窄布局、存储不足/不可用和数据库故障。

真实 OCR/模型调用需要授权和费用上限。通用键盘自由输入、广泛真人/设备测试、分布式负载/长稳测试及恢复 SLA 仍未完成。历史硬件测试使用合成声音，不是人类语音，也未在每个后续版本重复。

## 待执行质量基准——不是已测结果

用获准或公开书籍建立 25 题：8 道直接事实、6 道改写问法、4 道跨章综合、3 道精确术语、4 道不可回答题。固定输入比较纯向量、混合检索、混合加多样性筛选，记录模型/版本/日期、网络、标准答案和人工判断。

| 指标 | 建议目标 | 测法 |
| --- | --- | --- |
| Passage recall@6 | ≥ 0.84 | 六段中至少一段命中正确页 |
| 引用精确率 | ≥ 0.90 | 人工核对每条结论的原文支持 |
| 有据程度 | ≥ 4/5 | 人工评分并惩罚无依据内容 |
| 不可回答识别 | ≥ 0.75 | 正确承认证据不足 |
| 语音完成率 | ≥ 0.90 | 转写→回答→播放无需恢复 |
| 回答中位延迟 | < 8 秒 | 提交到可见回答，同时报告 p95 |

以上不是实测成绩或 SLA，不能用离线测试数量证明达标。日期化观察与失败见[历史实验](EVALUATION-LOG.zh-CN.md)，剩余工作见[生产准入](OPERATIONS.zh-CN.md#全面开放前的检查项)。
