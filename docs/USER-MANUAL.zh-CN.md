# Voicebook 用户手册

[中文项目介绍](../README.zh-CN.md) · [English project overview](../README.md)

适用对象：首次使用者、面试官与网站管理员。更新日期：2026 年 10 月 19 日。

Voicebook 是一个以语音为主要入口的读书问答网站。选择一本书，直接说出问题，即可看到识别文字、阅读带原文引用的回答，并听取语音讲解。你也可以查看书籍内容、调整回答方式，以及提交改进建议。

网站入口：[打开 Voicebook](https://voicebook-rag-demo.deep-hare-2593.chatgpt.site)。使用网站自己的账号登录，不需要 ChatGPT 账号，也不用填写 API key。本手册用中文说明，按钮名称按当前页面保留。

## 1 五分钟开始体验

界面现统一为英文。下文用中文解释功能；偏好面板的 Tone、Answer length、Custom preferences 分别对应语气、长度和自定义偏好，Brief / Balanced / Detailed 对应简短 / 适中 / 详细。

第一次使用，建议先选示例书，免去上传和处理 PDF 的等待。

1. 打开网站，点击 **New to Voicebook? Create an account**，填写用户名、密码和确认密码，点击 **Create account**。成功后，用刚创建的账号点击 **Sign in** 登录。
2. 在首页点击 **No book handy? Try a sample**，或在 Local library 点击 **Browse sample books**。选择一本书，点击 **Use this sample**。
3. 确认 **NOW READING** 显示所选书名。点击 **Start voice conversation**，允许浏览器使用麦克风，等到 **Listening — go ahead**。
4. 说：“请用中文介绍这本书的核心观点。”说完稍作停顿，网站会把转写放进 **You** 消息并自动发送，无需再点发送。
5. 等待回答和自动语音播放。点击回答中的数字引用，核对它依据了哪段书中文字。
6. 继续追问：“刚才第二个观点是什么意思？举一个例子。”体验上下文衔接。结束时点击 **End voice**。
7. 点击 **Reading preferences**，将回答长度改为“简短”，填入“先给结论，少用列表”，点击 **Save preferences**。再问一个问题，比较表达方式。

不方便开麦克风时，可点击页面提供的建议问题体验问答。当前没有常驻的自由文本输入框；异常情况下的未发送语音消息可能显示文字编辑和发送按钮。

## 2 注册与登录

### 创建普通账号

用户名为 3–32 个英文字母、数字、点、短横线或下划线，不区分大小写；密码为 10–128 个字符。注册成功后需要再登录一次，请妥善保存密码。

全站每天最多接受 **2 个成功的自助注册**，不是每个人都能注册两个。名额在新加坡时间每天 00:00 重置，注册页显示当天余量。名额已满时，可以等次日，或请管理员创建普通账号；管理员创建账号不占用这两个名额。

自助注册得到的是普通用户账号，没有管理后台权限。默认每日可提问 20 次、使用 10 分钟语音输入，实际可用量还受管理员设置和全站 AI 预算影响。

### 退出与再次使用

右上角显示当前账号，旁边的退出图标用于登出。再次在同一浏览器登录同一账号，可以重新打开已保存的书和对话。换浏览器或设备不会自动带来原来的私人书库，迁移方法见第 8 节。

## 3 选书与上传

### 选择已有书籍

在 **Local library** 点击书名即可开始。也可以从首页 **Choose from library** 进入。确认 **NOW READING** 中的书名后再提问，每次对话围绕当前选中的一本书展开，不是跨书搜索。

网站支持保存多本书，不会因为打开另一份 PDF 而替换整座书库。已处理过的书会复用保存的文字、段落和检索索引，再次选择不需要重新处理。正在进行语音对话时，先点击 **End voice**，再切换书籍。

### 上传自己的 PDF

1. 点击 **Upload a PDF**，或 Local library 标题旁的 **＋**。
2. 选择 PDF 文件。普通文本 PDF 会先直接提取文字；缺少可提取文字的页面会尝试 OCR，也就是从页面图片中识别文字。
3. 等待页面读取、文字识别和索引处理完成。处理期间保持页面打开，避免重复上传。
4. 书籍加入 Local library 且显示已就绪后，就可以提问。后续从书库选中即可，无需再次上传。

扫描版 PDF 通常更慢，因为相关页面需要调用云端 OCR。模糊、复杂排版或特殊字体可能导致漏字、错字；遇到可疑回答，请在 **Book management → Content** 检查原文和识别结果。文件能否顺利处理还取决于网络、浏览器空间以及索引和全站预算额度。

### 使用云端示例书

示例书是为演示准备的 AI 创作英文短读物，不是其他用户上传的私人书籍。可以用中文提问并要求中文解释。

点击 **Use this sample** 会在当前账号、当前浏览器中保存一份副本；已经保存时显示 **Open my copy**。选择示例不重新生成索引，也不扣提问次数；对它提问仍会使用正常的 AI 额度。删除自己的示例副本，不会删除公共模板或其他人的副本。

## 4 语音对话

### 一轮对话怎样进行

点击 **Start voice conversation** 后，网站开始监听。你说话时，音量图形会变化，并显示 **I can hear you**。说完停顿约一秒，或点击 **Done speaking**，即可结束这一段输入。

接下来会显示 **Transcribing your words…**。识别完成后，文字出现在聊天栏的 **You** 消息中并自动发送。它不是逐字实时字幕，较长的一段话要等转写结束才会显示。

网站随后检索书中段落、生成文字回答，再生成并自动播放声音。等待期间，你的问题会保留在聊天栏。当前是分阶段处理，不是零延迟的实时语音连接；网络或长回答可能增加等待时间。单段语音最长约 58 秒，长问题建议分段表达。

### 常用控制

| 按钮 | 作用 |
| --- | --- |
| Start voice conversation | 开启麦克风，开始连续语音对话。 |
| Done speaking | 提前结束当前这段说话，开始转写；不会退出语音模式。 |
| Mute microphone | 暂停收音；不等于停止正在生成或播放的回答。 |
| Resume microphone | 恢复收音。 |
| Stop reply | 停止当前回答的生成或播放；已显示的问题和回答文字仍保留。按钮位于 AI 回答区域。 |
| End voice | 结束语音模式并关闭麦克风，也会停止当前回复流程。 |
| Retry reply | 对失败或被停止的问题重试；可能再次消耗额度，不会复制出另一条相同问题。 |
| Play saved audio | 重播当前页面已取得的音频，不重新生成；刷新后不保证仍可用，曾被打断的音频可能只有一部分。 |

### 打断与纠正

AI 播放时可以直接开口。检测到输入会先暂停播放，确认识别到新的文字后，再终止旧回复并处理新问题；没有识别到文字时会尝试继续原回复。旧回答文字不会因为打断而消失。

如果转写错了，可以直接说：“刚才我说的是书里的观点，不是你的观点，请重新回答。”正常转写会自动发送，不设发送前确认步骤。

遇到转写失败、输入上限或中途暂停等异常，已识别的文字可能保留为 **Not sent**。这时在原消息内检查或修改，再点击 **Send question**；不想发送则选择 **Leave unsent**。未发送文字不会被当成已提交问题加入模型上下文。

使用时尽量处于安静环境。耳机可以减少扬声器回声；声音图形有变化只表示收到了声音，不保证识别文字正确。持续没有新输入时，网站也会自动结束收音；离开前仍建议主动点击 **End voice**。

## 5 查看回答依据

回答中的数字引用指向本轮检索到的书籍段落。右侧 **Evidence desk → Retrieved passages** 展示相应证据。

1. 点击回答里的数字，或对应的来源卡片，查看完整段落。
2. 点击 **View in book**，进入图书管理并定位相关段落。
3. 如果该书保存了原始 PDF 且有页码，可以再点 **View PDF page** 查看对应页面。

看到 **Saved passage · page unavailable**，表示这份已存段落没有可靠页码，不是页面加载失败。旧书库导入和纯文本示例可能没有原始 PDF。

引用有助于核对，不代表回答一定正确。尤其要区分“作者原文的观点”和“AI 为帮助理解给出的例子或建议”。若本轮证据不足，可以换个更具体的问题；“没有找到”也不等于整本书一定没有谈到。

## 6 调整阅读偏好

结束语音模式后，点击 **Reading preferences**。修改后务必点击 **Save preferences**，设置才会应用到之后的回答。

| 设置 | 可选内容与用途 |
| --- | --- |
| 语气 | 自然直接、亲切易懂、严谨深入。 |
| 回答长度 | 简短、适中、详细；这是篇幅倾向，不是严格字数承诺。 |
| 我的偏好 | 最多 600 个字符，例如“先给结论，遇到术语用日常语言解释，少用列表”。 |
| 在本机完整保存每本书的对话 | 默认开启；历史保存在当前浏览器，按账号和书籍分开。关闭的影响见第 9 节。 |

可以试用这条偏好：“先用一个日常比喻解释，再给结论；比喻请说明是例子，不要当作原文。”

当前问题里的明确要求优先于长期偏好。例如，平时选择“详细”，这一轮说“只用一句话回答”，网站仍会优先按本轮要求组织回答。偏好影响表达方式，不应改变书中事实或取消证据核对。

这些功能通过请求中的指令和对话上下文调整回答，不是在重新训练模型。对话中的临时要求和自动摘要，也不会自动变成长期个人偏好。

## 7 评价回答与按建议重答

每条完整回答下方有 **这次回答有帮助吗？**。点击赞或踩，可以选择“语气生硬”“太长”“不够详细”“没答到点”“引用有问题”，并填写修改建议。

下面三个操作用途不同，可以按需要分别使用：

| 操作 | 发生什么 |
| --- | --- |
| 提交评价 | 把本次问题、回答、书名、评分和建议发送给管理员，不自动改个人偏好，也不会自动重答。 |
| 按建议重答（1 次额度） | 使用标签和文字建议重新回答本题，消耗 1 次提问额度。 |
| 将文字建议记为偏好 | 将填写的文字建议追加为账号的长期偏好，可再去“阅读偏好”修改。仅选择标签还不能执行这个操作。 |

例如，只想让本次回答短一点，就填写“只用一句话，不要额外理由”并选择重答；希望以后都更简洁，再显式保存为偏好。

提交评价会分享这一轮的问题和回答给管理员。提交前请确认其中没有你不愿分享的私人信息；它不会把其他聊天或整本书一并作为反馈上传。

## 8 管理书籍与备份

顶部 **Book management** 用于管理书库，**Chat** 用于对话。进入图书管理后，可搜索书名、选书、上传 PDF 或选择示例。

### 检查和预览一本书

- **Overview**：查看书籍是否就绪、页数和段落数量等信息。折叠的 **Technical details** 用于排查索引问题，日常使用不需要展开。
- **Content**：有原始 PDF 时可以翻页和缩放；没有 PDF 时显示 **Text edition** 和保存的文字。
- **Show passages**：查看检索使用的文字段落，可以按关键词搜索、按章节筛选和翻页。这里的 passage 或 chunk 就是将书籍拆分后用于查找证据的一段文字，不需要理解向量数字。
- **Chat with this book**：将选中的书打开为当前对话对象。仅预览其他书，不会自动切换正在对话的书。

预览书籍和检查已存段落不会重新 OCR 或建立索引。**Remove** 会删除当前账号在这个浏览器中的该书副本及相关对话；操作前请先备份。

### 下载书籍备份

1. 选中要备份的书，展开 **Backup & restore**。
2. 输入至少 12 个字符的备份口令，点击 **Download selected book**。
3. 保存下载的加密文件，并将口令保存在另一处。网站无法找回备份口令。
4. 多本书请分别备份。备份包含该书可用的原 PDF、文字、索引及已保存的对话，不包含尚未保存到本机的临时对话。

备份在浏览器本地完成，不上传书籍，也不重新生成索引。较大的书可能超出备份大小限制，请另行保存原 PDF。

### 恢复到另一浏览器

在同一网站登录**同一个账号**，进入 **Book management → Backup & restore**，选择 **Encrypted book backup** 文件、输入口令，点击 **Restore book**。成功后按提示刷新，再打开书籍。

其他账号的备份不能恢复到当前账号。已有书籍的不同索引不会被直接覆盖，已有对话优先保留；如提示冲突，请保留两份文件并联系管理员，不要先删掉原数据再尝试。

## 9 对话记忆与隐私

默认会在本机保存每本书的全部对话，不再固定只留最近 20 轮。短对话参考全部前文；长到超出上下文预算时，使用早期内容的摘要，并找回相关原始消息。摘要不会替换原记录，但模型不保证记住每一个细节。

**重要：关闭“在本机完整保存每本书的对话”并保存，会清除该账号在当前浏览器中已经保存的对话历史，不只是停止保存新消息。** 当前页面仍可继续对话，但刷新后不恢复这部分聊天。“清空本机对话”也会清除此账号本机各本书的历史。需要保留时请先按书备份。书籍和索引、显式个人偏好与对话历史分别管理。

| 数据 | 保存或处理位置 |
| --- | --- |
| 私人 PDF、文字、索引和对话历史 | 当前浏览器，按账号及书籍隔离；不自动同步到云端书库。 |
| 账号、每日用量、阅读偏好和已提交评价 | 网站后端；偏好随账号保存。 |
| 云端示例书 | 网站提供只读模板，选中后在你的本机书库生成副本。 |
| 语音、OCR 页面、索引文字和问答上下文 | 使用对应功能时，经网站后端发送给配置的 AI 服务处理。不能将“本机保存”理解为“内容绝不离开设备”。 |

清除网站数据、使用无痕模式、换设备或换浏览器，都可能让本机书库无法继续使用。网站可以在开发者电脑关闭时访问，但不会因此从云端恢复你的私人书籍。

账号隔离不是本机磁盘加密。请不要在不信任的公共电脑上长期保存敏感文件，也不要把账号密码或备份口令写进聊天或反馈。

## 10 查看额度与处理限制

右上角账号左侧显示 **今日剩余 / 每日总额**，包括提问次数和语音时长。语音时间指输入录音，不是 AI 朗读的时长，也不是网页打开的总时长。空识别或失败尝试仍可能已经消耗输入额度。

每日额度按新加坡时间 00:00 重置，管理员可以调整个人额度。点击重答、重试或在请求已经被接受后停止，不保证退回消耗的额度。

另外，全站共用 AI 预算与并发保护，上传索引也有独立限制。因此，即使个人还有次数，也可能遇到全站暂停、繁忙或预算不足。此时稍后重试，或联系管理员；反复刷新不会重置额度。

## 11 常见问题

| 现象 | 建议操作 |
| --- | --- |
| Create account 不可点击 | 查看是否还有当日名额、是否加载成功，以及必填项是否填写。名额用完请找管理员。 |
| 无法登录或忘记密码 | 检查用户名和密码；当前没有邮件找回流程，请联系管理员处理访问问题。 |
| 麦克风没有反应 | 检查网站和操作系统的麦克风权限、输入设备以及是否处于 Mute；重新开启语音会话。 |
| 有波形但显示 No words detected | 收到了声音但没有可用文字。靠近麦克风、降低背景噪声，再说一次；先看聊天栏是否已经保留了此前的文字。 |
| 出现 Not sent | 等当前转写结束，在原消息中检查文字，再选择 Send question 或 Leave unsent。 |
| 回答有文字但没声音 | 检查系统音量、输出设备和网页静音状态；若出现 Play saved audio，可手动播放。也可能是语音服务失败，文字回答仍可阅读。 |
| Reply failed 或 AI is paused, busy… | 查看个人额度，稍后重试；持续出现则请管理员检查全站预算、暂停状态和服务健康。 |
| PDF 处理很慢 | 扫描页需要 OCR，长书还需要建立索引。保持页面打开，避免重复提交；首次体验先用示例书。 |
| 看不到 PDF 或页码 | 示例书和旧导入可能只有文字。使用 Content 或 Show passages 查看，不要把未知页码当作真实页码。 |
| 换电脑后书不见了 | 私人书库不跨设备同步。用同一账号恢复此前下载的书籍备份。 |
| 偏好没有影响旧回答 | 保存的偏好主要作用于之后的新回答；想改旧回答，使用“按建议重答”。 |
| 语音模式中无法切书或修改偏好 | 先 End voice，待当前工作结束后再操作。 |

## 12 管理员使用说明

普通读者不需要管理后台。管理员登录后，点击顶部 **Admin**：

1. **Create reviewer account**：为面试官创建普通账号，并通过合适的私密渠道交付账号信息，不要公开管理员密码。
2. **User allowances**：查看当天使用量，调整 **Daily questions** 和 **Daily voice**，点击对应行的 **Save**。这改变每日上限，不等于清零当天已用量。
3. **Health, budget & recovery**：查看健康状态、错误和用量信息，调整全站预算，必要时暂停新的 AI 请求。当前默认全站预算为每天 US$5，属于应用估算保护，不是供应商账单上限。
4. 查看用户提交的评价，了解回答质量问题；管理员不会因此获得浏览器里所有私人书籍和聊天。
5. **Encrypted server backup & restore** 用于手动下载服务端加密备份，与读者的本机书籍备份是两种数据。恢复会替换服务端数据，不应作为日常体验步骤。

面试验收前，确认账号可用、额度足够、AI 未暂停、示例书能打开即可。建议为面试官预备普通账号作为注册名额用完时的备用入口。

详细运维步骤见 [备份与恢复说明](BACKUP-RESTORE.zh-CN.md) 和 [运维手册](OPERATIONS.zh-CN.md)。
