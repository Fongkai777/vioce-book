# AI 费用计算

[English](PRICING.md) · [中文项目首页](../README.zh-CN.md)

本文对应仓库 2026 年 10 月 19 日记录的 v2 计价策略，不表示费率会自动跟随供应商变化。全站默认每天 **US$5**，按新加坡时间 00:00 重置；这是本应用的支出估算，不是供应商账单硬上限，也不覆盖同一 key 在其他程序的使用。

## 策略使用的标准费率

单位为美元/百万 token，不含税、议价、赠金及非标准服务档位。部署时应重新核对供应商价格与账单。

## 先预留再结算

1. 只有 `https://api.openai.com/v1/` 下精确支持的模型或快照使用这些费率。代理、未知模型和旧通义 embedding 使用明确标注的 v1 回退估算，不把 OpenAI 美元价格套到其他供应商。
2. 文本请求先按序列化 UTF-8 字节数加 256 的开销估计输入 token，并按请求实际输出上限预留输出费。这不是精确分词计数，而是取得响应前的保守预留。OCR 固定先留 $0.50，因为 base64 长度不能当图片 token。
3. 成功响应的有效 `usage` 替换本请求预留；缓存与非缓存输入分别计算，输出已包含推理 token，不重复相加。Embedding 使用 `prompt_tokens`。费用向上取整至美元微单位，最低一个微单位。
4. 结算与日总额调整在一个幂等 D1 事务内完成，归属最初接受请求的日期，即使跨新加坡零点或租约过期也不变。并发不能重复释放预留。真实费用若超过预留，会如实记录而不是截断；后续请求受预算阻止，因此不能保证供应商硬封顶。
5. 缺失、畸形、模型不匹配的 usage、非 2xx、超时或中断读取均保留预留。结算失败只记录元数据事件并保留原估算。报错或按 Stop 不代表供应商没收费。个人额度另计：费用结算不处理其退还，但服务器原因导致接口失败时有独立的自动退还机制；调用方主动取消不退，之前成功的步骤仍计入。详见[运维说明](OPERATIONS.zh-CN.md#费用与请求限制)。

例如按上述 gpt-5-mini 费率，10,000 个非缓存输入 token 加 1,000 个输出 token 为 **$0.0045**。输入包含系统指令、检索段落和历史，不只包括用户当前问题。

## 音频边界

转写只接受应用生成的规范 16 kHz、单声道、16 位 PCM WAV。服务器检查格式、精确数据长度和大于 0、不超过 60 秒的时长，不信任浏览器声明的 `durationSeconds`；压缩、歧义或伪造容器在扣额和模型调用前拒绝。

转写预留使用两倍按分钟参考估算，加完整 2,000 输出 token 上限和 512 输入 token 余量；有效 usage 到达后结算，缺失则保留该估算，而不是旧固定一美元。

TTS 返回二进制 MP3，不含 usage，**仍是估算**：文本字节上界按 $0.60/M，加每 Unicode 字符 20 个输出音频 token（最低 500）的启发式估计，按 $12/M 计算。它不是测得的音频 token，也不保证上界。界面策略名为 `openai-tts-estimate-2026-10-19`；未来可增加带可靠 usage 的流式返回，当前未宣称音频全部准确计量。

## 管理员展示与旧数据

总额分为按 usage 计价、估算或待处理、旧或恢复费用；模型表展示供应商报告的输入/缓存/输出 token、请求数、结算与估算。旧记录缺少 token 不补造，部署也不重置或重算当天已有总额。

管理员每天可显式确认一次 **Clear today's legacy estimates**。该操作只移除当天总额中未被 v2 成本和预留明细覆盖的部分，并在事务内精确校验日期和金额。新费用、请求数、个人额度、历史日期和预算上限保持不变。审计记录管理员、移除金额及前后总额；过期或重复请求不再扣除。这是预算调整，不是供应商退款或删除账务证据。旧备份可能恢复旧总额，但一次性审计标记保留，不能再次自动清理。

`operations_costs` 只记录请求 ID、日期、模型、价格策略、金额和 token，不含用户 ID、提示、段落、音频或凭据。同站点恢复保留明细和控制面；当前备份只包含每日聚合，不包含该诊断明细，因此新实例恢复后归为旧/恢复估算。迁移为增量，不回填或删除已有数据。

## 验证

离线测试覆盖费率算术、缓存、推理 token、非法 usage、未知/代理回退、WAV 校验、幂等结算、超预留费用、并发、跨日和旧总额保留，使用合成 usage 而非付费请求。需定期对照真实账单；单元测试不能证明供应商永不改价。
